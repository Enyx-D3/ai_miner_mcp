# Brain2Shot Runtime Rules — Universal Translator

Canonical loop:
compile → retrieve/acquire → experiment → measure → judge → repair → regression-check → persist → reopen → VEGA verify → CONTROL commit → residual-search → continue.

Durable progress requires one of:
- new real/verified corpus or source
- completed bounded experiment with raw evidence
- hypothesis upgraded/downgraded
- failure added to regression library
- verified mechanism gain
- verified falsification
- new canonical checkpoint

A web search, narration, dashboard refresh, or unchanged rewrite is not progress.

Single writer:
CONTROL only.

Checkpoint:
SAVE → VERIFY → CONTINUE.

Stop only when:
- terminal scientific gates are resolved; or
- all remaining useful branches are genuinely blocked.
